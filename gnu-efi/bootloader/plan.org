* UEFI Configuration Table

Vendor-provided mapping of GUID to Pointer.

- =aarch64= Goal :: Find base of flattened device tree.
- =x86_64= Goal :: Find base of ACPI RSDP 2.0+.

This will allow the kernel to properly enumerate the hardware of the machine upon startup.
